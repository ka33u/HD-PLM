另提供完整 BOM 浏览器回归 `npm run test:browser`，覆盖大 BOM、项目、制造、采购、附件、交接、继承与模板等操作；真实 ERP 样本可通过 `NPI_SAMPLE_DIR` 提供，不提交到仓库。

本机没有 Docker 引擎；容器配置已提供，本轮不将配置校验视为容器运行验收。
